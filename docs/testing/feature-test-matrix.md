## Masaiverse v2 publish visibility + admin create
- Area: Draft/publish visibility (`src/server/api/masaiverse-v2/services/publishVisibility.ts`) threaded through every event/club read service + handler; admin create (`services/{createEvent,createClub}.service.ts`, `handlers/{createEvent,createClub}.handler.ts`, `components/features/masaiverse-v2/AdminCreateButton.tsx`)
- Status: Covered
- Test files: `publishVisibility.service.test.ts`, `createEvent.service.test.ts`, `createClub.service.test.ts`, `createEvent.handler.test.ts`, `createClub.handler.test.ts`, `AdminCreateButton.test.tsx`; updated `getMasaiverseV2Home.service.test.ts`, `getClubDetail.service.test.ts`, `getClubEvents.service.test.ts`, `getHomeClubs.service.test.ts`, and the events/clubs read handler tests to assert the `canSeeUnpublished` flag is threaded through.
- Notes: Events/clubs carry `meta.isPublished` (+ `meta.lastEditedBy` / `meta.lastEditedAt`). A row is hidden from a viewer unless `canSeeUnpublished = isAdmin && adminModeEnabled`. Visibility is **strict**: only an explicit `meta.isPublished === true` is shown to non-admins — a missing or `false` flag counts as unpublished and is hidden (so pre-existing rows without the key are hidden until published). `canSeeUnpublished` is computed in each read handler (the auth boundary) and passed into every event read (`getEventsList`, `getEventDetail`, `getHomeEvents`, `getHomeHighlights`, `getClubWeeklyConnects`, `getEventsThisYearCount`) and club read (`getHomeClubs`, `getClubDetail`, `getMyClubs`, `getClubEvents`, `getClubStats`, `getClubLeaderboard`), and forwarded from the home/club-detail orchestrators to their sub-services. Legacy v1 `fetchAllEvents`/`fetchAllClubs` exclude drafts too. Detail reads return null (→ 404) for a hidden draft. Admins with admin mode on get an "Add an event"/"Add a club" CTA that POSTs to `/events/create` / `/clubs/create`; the server gates on the DB admin role (403 otherwise) and inserts a placeholder draft (`isPublished:false`, dummy images), then the client invalidates the events/home lists. Toggling admin mode reloads the page so all lists refetch with the new visibility. Beyond drafts, admin mode is a **full view that drops membership scoping**: `getEventsList` returns every event (no `visibleClubIds` scope) and `getMyClubs` returns *every* club (not just joined) — which in turn gives the discussions and leaderboard pages a tab for every club, and the events page every event. The global leaderboard and club-scoped discussion/leaderboard reads already have no membership gate.
